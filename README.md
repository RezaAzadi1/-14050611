# ربات تلگرامی محاسبه‌گر تهاتر هات رول ← ورق رنگی

## نصب

```bash
pip install -r requirements.txt
```

## گرفتن توکن ربات

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید.
2. دستور `/newbot` را بزنید و مراحل را طی کنید.
3. توکنی که می‌دهد را کپی کنید.

## اجرا

```bash
export TELEGRAM_BOT_TOKEN="توکن شما"
python bot.py
```

## نحوه استفاده در تلگرام

1. به ربات پیام `/start` بدهید.
2. قیمت هات رول را به تومان بر کیلوگرم وارد کنید (مثلاً `121000`).
3. وزن ورق رنگی موردنیاز را به تن وارد کنید (مثلاً `386`).
4. نرخ کارمزد تبدیل را به تومان بر کیلوگرم وارد کنید (مثلاً `70000`).
5. ربات جدول کامل ریز محاسبات (وزن هات رول موردنیاز، ریز ضایعات و ارزش هرکدام،
   افت اسیدشویی، هزینه‌های نقدی و قیمت تمام‌شده هر کیلوگرم) را ارسال می‌کند.

## پارامترهای ثابت (قابل تغییر در بالای فایل bot.py)

این‌ها از کاربر پرسیده نمی‌شوند و در کد ثابت‌اند — طبق داده‌های فعلی کارخانه:

| پارامتر | مقدار |
|---|---|
| هزینه حمل | ۲٬۵۰۰ تومان/کیلوگرم |
| افت اسیدشویی | ۰٫۵٪ (بدون بازگشت) |
| نیمچه کویل گالوالوم | ۱٪ — قیمت فروش ۱۱۰٬۰۰۰ تومان/کیلوگرم |
| نیمچه کویل رنگی | ۱٪ — قیمت فروش ۱۳۰٬۰۰۰ تومان/کیلوگرم |
| نیمچه کویل فول‌هارد | ۵٪ — قیمت فروش ۱۰۰٬۰۰۰ تومان/کیلوگرم |
| سرقیچی گالوالوم | ۰٫۵٪ — قیمت فروش ۸۵٬۰۰۰ تومان/کیلوگرم |
| سرقیچی رنگی | ۰٫۵٪ — قیمت فروش ۱۰۰٬۰۰۰ تومان/کیلوگرم |

اگر این نرخ‌ها یا درصدها تغییر کرد، فقط کافیست لیست `WASTE_ITEMS` و متغیر
`TRANSPORT_PRICE` در ابتدای فایل `bot.py` را ویرایش کنید — بقیه‌ی محاسبات
خودکار به‌روز می‌شود.
